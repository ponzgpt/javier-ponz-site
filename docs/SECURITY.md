# Security and privacy

- No secrets, credentials, cookies or tokens are stored in the repository.
- Contact uses a `mailto:` link; there is no server-side form or data collection endpoint.
- External links use `rel="noreferrer"` where applicable.
- Nginx sends `X-Content-Type-Options`, `Referrer-Policy` and `Permissions-Policy` headers.
- The site is static and has no runtime database.
- Review third-party font hosting before treating the site as privacy-minimal; self-host fonts in a later iteration if required.
